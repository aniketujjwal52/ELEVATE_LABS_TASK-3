# SQL for Data Analysis

## Objective
The objective of this task is to practice SQL by performing data analysis on an ecommerce dataset.

## Tools Used
- PostgreSQL
- pgAdmin 4

## Dataset
Olist Ecommerce Dataset

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Aggregate Functions (SUM, AVG)
- Subquery
- View
- Index

## Outcome
Learned how to retrieve, filter, join and analyze structured data using SQL queries.
